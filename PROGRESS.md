# Progreso de práctica

Marca un problema como dominado solo si puedes resolverlo sin ayuda, probarlo y explicar su complejidad.

## Escala

| Nivel | Descripción |
|---:|---|
| 0 | No reconozco el patrón |
| 1 | Entiendo una solución explicada |
| 2 | Resuelvo con pistas |
| 3 | Resuelvo solo, pero lento o con bugs |
| 4 | Resuelvo dentro del tiempo objetivo |
| 5 | Resuelvo, pruebo y explico con seguridad |

## Repetición

- **Nivel 0–2:** repetir al día siguiente.
- **Nivel 3:** repetir en 2 días.
- **Nivel 4:** repetir en una semana.
- **Nivel 5:** mantener mediante simulaciones.
