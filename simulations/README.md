# Simulaciones de 70 minutos

Cada set contiene cuatro problemas. No abras los enlaces antes de iniciar el cronómetro.

## Protocolo

1. Lee los cuatro problemas durante los primeros cinco minutos.
2. Ordénalos por dificultad percibida.
3. Cambia de pregunta tras 8–10 minutos sin código ejecutable.
4. Conserva cinco minutos para pruebas.
5. Registra el resultado en [RESULTS.md](RESULTS.md).
