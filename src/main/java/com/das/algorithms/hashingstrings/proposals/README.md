# Propuestas para dominar hashing y strings

Orden recomendado:

1. [Valid Anagram](01-valid-anagram.md) — frecuencias básicas.
2. [Two Sum (unsorted input)](02-two-sum.md) — búsqueda de complementos con `HashMap`.
3. [Longest Consecutive Sequence](03-longest-consecutive-sequence.md) — diseño de recorrido con `HashSet`.

> **Distinción importante:** esta versión recibe un arreglo desordenado y su patrón principal es hashing.  
> [Two Sum II](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/) recibe un arreglo ordenado y su patrón principal sí es Two Pointers.
