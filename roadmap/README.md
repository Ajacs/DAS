# Roadmap después del assessment

Orden sugerido para ampliar el repositorio:

1. `stack/` — Valid Parentheses, Daily Temperatures, Largest Rectangle.
2. `binarysearch/` — búsqueda exacta, boundaries, respuesta monotónica.
3. `linkedlists/` — reversión, fast/slow, merge.
4. `trees/` — DFS, BFS, BST y LCA.
5. `heap/` — Top K, merge K lists y streaming.
6. `intervals/` — merge, insert y scheduling.
7. `greedy/` — Jump Game e interval scheduling.
8. `dynamicprogramming/` — 1D, knapsack, strings y grids.
9. `unionfind/` — componentes dinámicos y Kruskal.

Para cada categoría:

- tres ejercicios resueltos;
- tres proposals;
- una nota de patrones;
- tests de edge cases;
- un README con orden recomendado.
